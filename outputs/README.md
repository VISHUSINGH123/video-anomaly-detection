# Outputs Directory

This directory contains evaluation summaries, single-video prediction CSVs, timeline plots, and optional annotated MP4 overlays.

## Structure
- `outputs/evaluation/`: Contains `evaluation_summary.json` and `per_video_summary.csv` generated by `scripts/evaluate.py`.
- `outputs/predictions/`: Contains `<video_id>_clip_scores.csv`, `<video_id>_frame_scores.csv`, `<video_id>_timeline.png`, and `<video_id>_annotated.mp4` generated by `scripts/predict_video.py`.
- `outputs/demo/`: Contains synthetic smoke-test artifacts generated by `scripts/generate_demo.py`.
